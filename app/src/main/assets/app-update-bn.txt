• অ্যাপ জুড়ে প্রাইমারি Cloudflare Worker URL এখন একই রাখা হয়েছে, এবং GitHub অটো-ডিপ্লয় ঠিক করা হয়েছে — আগে এটি ভুল Worker নাম ও ভুল টাইপ করা workers.dev সাবডোমেইনে পাঠাত।
• Admin → Server health এখন লাইভ Worker ভার্সন, Cloudflare ডেটা সেন্টার এবং অতিরিক্ত সার্ভিস চেক (ইমেইল, ওয়েব সার্চ, ওয়েব কম্প্যানিয়ন, APK ডাউনলোড লিংক) দেখায় এবং প্রতি মিনিটে নিজে থেকে রিফ্রেশ হয়।
• হেলথ চেক এখন সব Worker একসাথে (parallel) পরীক্ষা করে, তাই একটি ধীর বা অফলাইন নোড বাকিগুলোকে আর আটকে রাখে না।
• Worker কে API v50 (রিলিজ 4.7.0) তে আপগ্রেড করা হয়েছে, সাথে আরও বিস্তারিত ও সঠিক হেলথ রিপোর্ট।
• এই রিলিজ versionCode 52 / 4.4.6। আপডেটের পর Admin → Server health → Deploy থেকে একবার Worker রি-ডিপ্লয় করুন যাতে লাইভ API অ্যাপের সাথে মেলে।
