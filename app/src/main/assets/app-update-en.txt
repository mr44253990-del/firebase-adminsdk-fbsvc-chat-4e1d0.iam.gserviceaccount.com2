• The primary Cloudflare Worker URL is now consistent across the app, and the GitHub auto-deploy was fixed — it previously targeted the wrong Worker name and a mistyped workers.dev subdomain.
• Admin → Server health now shows the live Worker version, the Cloudflare data center, and extra service checks (email, web search, web companion, APK download link), and refreshes itself every minute.
• Health checks now probe all workers in parallel, so a slow or offline node no longer delays the rest.
• The Worker was upgraded to API v50 (release 4.7.0) with a more detailed, truthful health report.
• This release is versionCode 52 / 4.4.6. After updating, redeploy the Worker once from Admin → Server health → Deploy so the live API matches the app.
