# Working-tree implementation status — 2026-10-28

This is an **uncommitted working-tree update**, not a release. The last released/pushed baseline remains **v4.4.5 / versionCode 51**, commit `f994904`. Existing mode-only/pre-existing edits to `gradlew`, deployment scripts, the smoke script, and the worker test script are not part of this change and must not be staged.

## Changes implemented in source (not yet Android-build/CI/live-deployment verified)

- **Social feed pagination:** `posts` now has a live Firestore head query ordered by `timestamp DESC` and limited to 30 documents. The feed can fetch the next page using `startAfter(lastSnapshot)`. Room remains the quick first-paint cache. `HomeScreen` shows a bilingual Load more control.
- **Admin user-directory pagination:** the admin user page queries 50 profiles at a time by `createdAt DESC` and loads the next cursor page. The global app user listener is intentionally unchanged to avoid breaking shared friend/chat/mention/profile flows; therefore this is not yet a global reduction in all user reads.
- **Admin media-save policy:** new `FlagshipConfig.autoSaveReceivedFilesEnabled` defaults to the existing behavior. The admin can turn off automatic received-file downloads; local per-user preferences and per-file-type rules remain. Manual downloads and normal chat-message storage are not disabled. Both settings surfaces and the actual incoming-file auto-save path honor the remote flag. The user confirmed this files/media-only scope.
- **Bilingual in-app guide and tour:** bundled `app-guide-en.txt` / `app-guide-bn.txt`; Settings → More opens the offline guide. The spotlight tour version is advanced to v2 and adds profile/settings, location-sharing, media-saving and AI-history guidance. New tour strings have Bengali entries.
- **First-entry update summary plumbing:** bilingual update-summary assets and a first-entry welcome dialog are wired to the installed `BuildConfig.VERSION_CODE`; it uses version 51 as the prior shipped baseline, so it becomes visible when the next release bumps above 51. The dialog offers the whole-app tour, offline guide, or Not now. Do not release this as versionCode 51; bump the app version only after the intended release scope is finished.
- **Auto-AI post image delivery:** removed the direct Pollinations URL path. When the admin has enabled and configured OVH image generation and the Supabase public posts bucket/service-role environment is available, the scheduled function generates the image server-side, uploads a stable object and publishes its cacheable URL. If setup/provider/storage fails, the post uses its styled background rather than publishing a slow external generation URL. No OVH token or live deployment is present, so this path still needs configuration and live validation.
- **Opt-in web companion source:** new static Cloudflare Pages frontend under `web-companion/` and Worker `/web-pair/*` routes. Pairing is explicitly initiated in Android, uses a 10-digit one-use 90-second code, atomic Firestore consume, hashed opaque 12-hour session token in browser `sessionStorage`, exact configured HTTPS origin, IP-hash attempt throttling, all-session Android revocation and per-session browser logout. Worker proxy exposes accepted, unblocked one-to-one text chats only; it does not issue Firebase client tokens and does not expose service-account credentials. Worker API/client requirement is now 48. The user selected **Cloudflare Pages + the existing Worker**.
