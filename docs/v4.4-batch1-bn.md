# Convo Chat v4.4.0 — Batch 1 (প্রস্তুতির নোট)

## এই ব্যাচে যোগ করা হচ্ছে

- **Saved messages:** মেসেজের মেনু থেকে ডিভাইসে Save/Remove; Saved পেজ থেকে আবার চ্যাট খোলা যায়। একাধিক লগইন থাকলে তালিকা UID অনুযায়ী আলাদা।
- **Pinned message:** একটি চ্যাটে একটি বার্তা pin; চ্যাটের উপরে বার, ট্যাপ করলে লোড করা বার্তায় যায়।
- **Archive / Locked / Unread ফিল্টার:** চ্যাট সেটিংস থেকে archive, সব চ্যাট/অপঠিত/Archived/Locked তালিকা।
- **Chat lock:** আঙুলের ছাপ/ফোনের স্ক্রিন-লক দিয়ে chat gate; অ্যাপ background-এ গেলে সেশন relock হয়। Android-এ secure screen lock না থাকলে chat lock চালু করা যাবে না।
- **Global search (local):** এই ডিভাইসে Room-এ ক্যাশ হওয়া মেসেজের লেখা ও ফাইলনাম খোঁজে; এটি সার্ভার-সাইড/সব পুরনো cloud ইতিহাসের search নয়।
- **Message reminders:** মেনু থেকে ১৫ মিনিট, ১ ঘণ্টা, ৩ ঘণ্টা বা আগামীকালের reminder; Android inexact alarm, তাই Doze-এ কয়েক মিনিট দেরি হতে পারে। নোটিফিকেশন Android notification permission/channel মানে।
- **1:1 call history:** কল শেষ হলে এই ডিভাইসে সাম্প্রতিক তালিকায় থাকে; account অনুযায়ী আলাদা। গ্রুপ-কল history পরবর্তী কাজ।
- **AI Catch me up / Writing tools:** AI দিয়ে সাম্প্রতিক loaded conversation summary এবং খসড়া Polish/Shorten/Friendly/Bengali করা। বিদ্যমান AI worker/provider ব্যবহার করে; Privacy settings-এ AI বন্ধ থাকলে অনুরোধ প্রত্যাখ্যান হবে।
- **২৪ ঘণ্টার Notes:** chat list-এ নিজের ও বন্ধুর note; friends-only, ৮০ অক্ষর, server-এর বিদ্যমান `users` profile document-এ expiry timestamp-সহ।
- **Auto-download rules:** Wi-Fi-only এবং Images/Videos/Audio/PDF/Documents/Files-এর আলাদা switch। Existing save path `Downloads/Convo Chat/<type>` অপরিবর্তিত।
- **Launcher shortcuts:** আইকনে long-press করে AI, search, saved messages ও calls-এ যাওয়া। Android launcher-এর shortcut সীমা অনুযায়ী তালিকা ছোট হতে পারে।
- Version **46 / 4.4.0**.

## নতুন API key

এই ব্যাচের জন্য **নতুন API key লাগবে না**। AI-র জন্য আগের মতোই Worker-এ অন্তত একটি AI provider সক্রিয় ও secret/configured থাকতে হবে; Google Play Services/Android screen lock ব্যবহারে কোনো নতুন key নেই। Notes-এর জন্য Firestore access/rules-এ signed-in মালিকের নিজের `users/{uid}` document update অনুমোদিত থাকতে হবে (বর্তমান নিয়মে note field sensitive/admin-only field নয়)।

## প্রাথমিক যাচাইয়ের সীমা

এখনকার search স্থানীয় cache-এ সীমাবদ্ধ; call history শুধু 1:1 call। Reminder ফোন reboot-এর পর পুনরায় restore করার receiver এই ব্যাচে নেই। Chat lock ও saved/pinned data device-local; এগুলো অন্য ডিভাইসে sync হয় না। এগুলোকে cloud/E2EE/account deletion সম্পূর্ণ সমাধান বলে ধরা যাবে না।

## পরের ব্যাচের জন্য

Feature list-এ বাকি থাকা ফিচারগুলো—বিশেষত multi-select/forward, view-once, GIF/sticker search, media editor/document scanner, group-call history, storage manager, full server-wide search, account deletion/data export এবং প্রয়োজনীয় admin/Play Billing integration—এখনও আলাদা কাজ। E2EE, payment, call recording, AI transcription, Cloudflare R2/Stream-এর জন্য নিরাপত্তা/আইনি/বাণিজ্যিক সেটআপ আগে লাগবে।
