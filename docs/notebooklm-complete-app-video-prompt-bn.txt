ভিডিওর উদ্দেশ্য

- Version reference: v4.4.4 (versionCode 50) — এই version-এর visible/current features-ই বর্ণনা করবে।
- দর্শক: বাংলাদেশি Android ব্যবহারকারী, পরিবার/বন্ধু/কমিউনিটি, নতুন user ও বর্তমান user।
- লক্ষ্য: app-এর শুরু থেকে শেষ পর্যন্ত প্রধান screen/page দেখিয়ে—কী দেখা যায়, কী করা যায়, কী সুবিধা—ধাপে ধাপে শেখানো এবং একই সঙ্গে আকর্ষণীয় promotional video বানানো।

- Narration voice: একজন প্রাপ্তবয়স্ক বাংলাদেশি বাংলা নারী presenter; উষ্ণ, স্বচ্ছ, মাঝারি pitch, আত্মবিশ্বাসী কিন্তু বন্ধুসুলভ, শুদ্ধ ও সহজ উচ্চারণ, স্বাভাবিক Dhaka/Bangladesh বাংলা। robotic, অতিরিক্ত বিজ্ঞাপন-চিৎকার, পশ্চিমবঙ্গীয় টান বা অপ্রয়োজনীয় নাটকীয়তা নয়। গতি মাঝারি; নতুন feature-এ ছোট pause দিয়ে দর্শককে screen দেখতে দাও। “Convo Chat” বলবে “কনভো চ্যাট”; “AI” বলবে “এ-আই”; “OTP” বলবে “ও-টি-পি”; “QR” বলবে “কিউ-আর”।

সবচেয়ে গুরুত্বপূর্ণ factual rules
১. শুধু supplied source বা actual screen-এ দেখা feature-কে বর্তমান feature হিসেবে বলবে। কোনো feature source-এ “planned/roadmap/পরবর্তী” হলে ভিডিওতে দেখাবে না; সর্বোচ্চ শেষের “ভবিষ্যৎ পরিকল্পনা” অংশে স্পষ্টভাবে ভবিষ্যৎ বলে উল্লেখ করা যায়, তবে current feature-এর সঙ্গে মিশিও না।
২. end-to-end encryption আছে—এমন দাবি কোরো না। “সম্পূর্ণ নিরাপদ”, “hack করা অসম্ভব”, “সব মেসেজ encrypted” বা “সম্পূর্ণ private” ধরনের absolute security claim কোরো না।
৩. ভুয়া user count, rating, review, award, download সংখ্যা, active-user সংখ্যা, price, subscription plan price, market availability, guarantee, testimonial বা official download link বানাবে না। CTA-তে কোনো URL না থাকলে placeholder দিও না; শুধু app name ও neutral call-to-action ব্যবহার করো।
৪. Search-কে সব cloud history-র server-wide search বলবে না; current chat search cached/local messages-এ সীমিত হতে পারে। Call history 1:1 এবং device-local—cross-device cloud sync বলবে না।
৫. “Active/online” বা background presence ১০০% নির্ভুল/guaranteed বলবে না; app acknowledgment, network, Android battery/Doze, FCM ও device policy-তে নির্ভরতা আছে।
৬. AI Catch me up / Writing tools কেবল AI Worker/provider configured এবং user-এর AI privacy permission থাকলে কাজ করে। AI feature-কে opt-in সহায়তা হিসেবে দেখাও; AI কোনো message নিজে থেকে পাঠায় না।
৭. Phone sign-in-এ Firebase-এর instant verification/SMS auto-retrieval কিছু device/network-এ কাজ করে; সব ফোনে নিশ্চিত নয়। 2-step verification-এর method যা source-এ আছে শুধু সেটিই বলো; SMS-কে MFA method বলে দেখিও না যদি source-এ না থাকে।
৮. Notes-এর friend-only rules সঠিক Firebase project-এ deploy না থাকলে Notes read/write ব্যর্থ হতে পারে। Production screen record করার আগে rules deploy ও Notes পরীক্ষা করো; না হলে Notes-কে সক্ষম feature বলে দাবি কোরো না।
৯. Document scanner-এ Google Play Services component/network প্রথমবার লাগতে পারে। Storage manager কেবল Convo Chat তৈরি করা managed downloads দেখায়; অন্য app-এর Downloads মুছে দেয়—এমন দেখিও না।
১০. Premium, admin/staff, AI-config, flagship-config বা Android version-নির্ভর option সব user-এর জন্য আছে—এমন বলবে না। Screen-এ enabled থাকলেই দেখাবে এবং voiceover-এ “যাদের account/setting-এ সক্রিয়” বলে বোঝাবে।
১১. UI-তে decorative emoji যোগ কোরো না। User content/reaction হিসেবে screen recording-এ বাস্তব emoji থাকলে সেটি বদলানোর দরকার নেই।
১২. real user-এর personal chat, phone number, email, OTP, private photo, location, call identifier, service URL/API key/secret—কোনো কিছু প্রকাশ করবে না। Demo data ব্যবহার করো।

Visual / motion design
- Overall style: premium কিন্তু বিশ্বাসযোগ্য Android product film। Deep navy/charcoal base, violet/teal/cyan highlight, soft gradient glow, clean glass-like layers; app-এর বাস্তব theme-color বদলে নতুন UI বানাবে না।
- প্রথম frame-এ blank black screen নয়; দ্রুত, মসৃণ brand reveal, তারপর real app screen। শেষেও clean logo/title card।
- প্রত্যেক page-এর আগে 1–2 second chapter title; তারপর আসল screen recording বা supplied screenshot। UI-কে phone frame-এ বসালে bezel সরু ও natural; screen text distortion/AI-generated fake text থাকলে screen-টি replace করে actual capture ব্যবহার করো।
- Real interaction দেখাও: tap, scroll, open, close, save, filter, call, scan, paste, settings toggle। Feature screen-এ focus করতে soft zoom/pan, cursor/ripple, highlight outline বা ছোট arrow ব্যবহার করা যায়। আসল UI control-এর জায়গা বা function বদলাবে না।
- Transition: short camera push-in, clean slide, soft blur, card-to-card morph, phone-screen zoom. অতিরিক্ত glitch, flash, spinning transition, floating emoji বা overload নয়।
- Text overlay: সর্বোচ্চ 3–7 শব্দের ছোট Bengali benefit caption, বড় ও পড়তে সহজ; screen-এর উপর খুব বেশি লেখা নয়। Bengali glyph ঠিকভাবে যুক্ত হয়েছে যাচাই; সম্ভব হলে Noto Sans Bengali-ধাঁচের readable font। Broken কার/যুক্তাক্ষর/অস্পষ্ট small text রেখে দিও না।
- Voiceover-এর সঙ্গে subtitle অবশ্যই দাও: সঠিক বাংলা, line 1–2, safe-area-র মধ্যে, যথেষ্ট contrast। ইংরেজি UI label হলে exact screenshot spelling রাখো।
- Screen recording landscape video-তে বসানোর সময় chat text/notification/নাম blur বা dummy data দিয়ে replace করো।

সব scene-এর production rules
- উপরের timing guide; দরকার হলে source অনুযায়ী scene দীর্ঘ করো, কিন্তু screen order বজায় রাখো। Narration-কে তাড়াহুড়ো করে পড়ো না।
- Scene-এর আগে chapter card: ১–২ সেকেন্ড; screen demonstration-এ অন্তত ৩–৬ সেকেন্ড no-talking pause দাও যাতে দর্শক action বুঝতে পারে।
- প্রত্যেক scene-এ screen-এর পাশে 1টি short benefit label; একই শব্দ বারবার নয়। UI-তে actionটি বাস্তবে করে দেখাও।
- Actual screenshot/screen recording না থাকলে accurate text diagram ও phone outline ব্যবহার করো; hallucinated app screenshot বা fake settings নয়।
- UI screenshot-এর ratio বদলালে crop করে গুরুত্বপূর্ণ control কেটে ফেলো না। 16:9-এ phone center-left/right, পাশে বড় Bengali caption; phone screen-এ tiny text পড়া না গেলে separate zoom shot দাও।
- On-screen caption actual pronunciation/feature-এর সঙ্গে match করো। No price, URL, phone number, rating, download total, feature badge বা quote fabricate।
- Final quality check: Bengali captions joined glyph ঠিক; voice accent Bangladeshi; private data/secret visible নয়; all current feature claims source-এ আছে; roadmap feature accidentally current হিসেবে এসেছে কি না যাচাই; audio music ducked; logo correct; CTA-তে fake link নেই।
