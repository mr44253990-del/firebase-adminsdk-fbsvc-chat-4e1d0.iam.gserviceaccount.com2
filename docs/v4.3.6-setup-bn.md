# Convo Chat v4.3.6 — নতুন ফিচার ও সেটআপ গাইড

## ১. প্রথম কাজ: Worker আপডেট (API v46)
অনেক নতুন ফিচার (Gmail Connect, AI ওয়েব সার্চ, ফোন-লগইন কনফিগ, ই-মেইল ডায়াগনস্টিক) নতুন Worker ছাড়া কাজ করবে না।

- **অ্যাপ থেকে:** Admin → Server health → "Deploy Worker from this phone"।
  - Code: "Built into this app" অথবা নিজের `cloudflare-worker.js` ফাইল আপলোড।
  - Cloudflare API token দিন (dash.cloudflare.com → My Profile → API Tokens → "Edit Cloudflare Workers")।
  - "Verify" চাপলে টোকেন ও অ্যাকাউন্ট যাচাই হবে। চাইলে "Remember token" (Keystore-এ এনক্রিপ্টেড)।
  - "Deploy now" → প্রতিটি টার্গেটের ফল ও লাইভ হেলথ (API ভার্সন, latency, Firebase/AI/TURN/R2) দেখাবে।
  - একই জায়গা থেকে Worker secret (যেমন `TAVILY_API_KEY`, `GMAIL_SERVICE_ACCOUNT`) সেট করা যায়।
- **অটোমেটিক:** GitHub → Settings → Secrets → Actions → `CLOUDFLARE_API_TOKEN` যোগ করলে প্রতিটি push-এ Worker ডিপ্লয় হবে।

## ২. ই-মেইল প্রোভাইডার কাজ না করার কারণ
লাইভ Worker পুরনো ছিল (GitHub-এ ডিপ্লয় secret নেই বলে ডিপ্লয় স্কিপ হচ্ছিল)। Worker আপডেট করুন।
ই-মেইল প্যানেল এখন দেখায়: কোন প্রোভাইডার কেন স্কিপ হলো, Worker ভার্সন পুরনো কিনা, পড়তে সমস্যা কিনা।
মনে রাখবেন: gmail.com ঠিকানা Brevo/Resend দিয়ে From হিসেবে পাঠালে DMARC-এ আটকে যায় — নিজের ডোমেইন বা Gmail প্রোভাইডার ব্যবহার করুন।

## ৩. Gmail প্রোভাইডার (নতুন পদ্ধতি)
**পদ্ধতি ক — OAuth (সাধারণ Gmail অ্যাকাউন্ট):**
1. Google Cloud Console → APIs & Services → Gmail API Enable।
2. OAuth consent screen → External → **Publish app (In production)**। Testing মোডে টোকেন ৭ দিনে বাতিল হয়।
3. Credentials → Create OAuth client → **Web application**।
   Authorized redirect URI: `<আপনার Worker URL>/gmail/oauth/callback` (অ্যাপের ই-মেইল প্যানেলে কপি বাটন আছে)।
4. অ্যাপে Admin → Email → Gmail (OAuth) প্রোভাইডারে Client ID ও Secret দিন → **Connect Gmail**।
5. ব্রাউজারে লগইন শেষ হলে অ্যাপে অটো ফিরে আসবে। Refresh token সার্ভারে (`admin_secrets/email`) সেভ থাকে, আবার করতে হবে না।

**পদ্ধতি খ — Service account (Google Workspace ডোমেইন):**
Service account JSON → Worker secret `GMAIL_SERVICE_ACCOUNT`। Workspace Admin-এ domain-wide delegation দিয়ে scope `https://www.googleapis.com/auth/gmail.send` অনুমোদন করুন। সাধারণ @gmail.com-এ এটি কাজ করে না।

## ৪. AI আপগ্রেড
- নতুন ফিউচারিস্টিক Assistant পেজ: লাইভ স্ট্রিমিং উত্তর, ওয়েব সার্চ (সূত্রসহ), কণ্ঠে পড়ে শোনানো, মেমোরি।
- Admin → AI: "Live streaming replies", "Web search", "Human-like style" অন/অফ।
- ফ্রি AI প্রোভাইডার প্রিসেট: Groq, Cerebras, GitHub Models, SambaNova, Hugging Face, NVIDIA, OpenRouter, Mistral, Gemini ইত্যাদি — প্রতিটির নিচে ফ্রি-টিয়ার হিন্ট।
- ওয়েব সার্চ কী (ঐচ্ছিক, না দিলে DuckDuckGo/Wikipedia): Admin → AI → Web search-এ Tavily / Brave / Serper কী।

## ৫. AI পোস্ট
Admin → Auto AI posts:
- **AI picture in posts** — প্রতিটি পোস্টে মিলিয়ে AI ছবি (Pollinations, কী লাগে না)।
- **AI web search + link** — তাজা তথ্য ও সূত্রের লিংক। নতুন টাইপ "Fresh news"।
- **Part-by-part story series** — টপিক দিন, Part 1, Part 2 … আগেরটার ধারাবাহিকতায়; শেষ পার্টের পর নতুন গল্প শুরু।
সার্ভার (Supabase `auto-ai-post`) ফাংশনেও একই ফিচার আছে — `supabase functions deploy auto-ai-post` দিয়ে আপডেট করুন।

## ৬. ফোন নম্বর দিয়ে লগইন/সাইনআপ
1. Firebase Console → Authentication → Sign-in method → **Phone** Enable।
2. Project settings → Android app-এ release keystore-এর **SHA-1 ও SHA-256** যোগ করুন (Play Integrity-র জন্য দরকার)।
3. Google Cloud-এ **Play Integrity API** Enable (Firebase নিজে চায়)।
4. অ্যাপে Admin → Control center → "Sign-up & sign-in methods": E-mail / Phone চালু-বন্ধ, ডিফল্ট কান্ট্রি কোড (+880)।
5. লগইন স্ক্রিনের আগেই কনফিগ পড়তে Firestore rules ডিপ্লয় করুন (`app_config/auth_public` পাবলিক রিড)। না হলে Worker `/public/auth-config` থেকে পড়বে।

**কন্টাক্ট থেকে বন্ধু:** Messages ট্যাবে কার্ড → "Allow contacts"। ফোনের কন্টাক্ট নম্বর ডিভাইসেই হ্যাশ হয়, শুধু হ্যাশ মেলানো হয়। মিল পাওয়া মানুষ মেসেজ লিস্টে দেখা যায়। ই-মেইল ইউজাররা "Add my number" দিয়ে SMS যাচাই করে নম্বর যোগ করতে পারেন।
