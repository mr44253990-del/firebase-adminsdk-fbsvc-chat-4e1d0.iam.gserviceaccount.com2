## নতুন API key লাগবে কি?

এই feature batch-গুলোর জন্য **নতুন API key লাগে না**। AI summary ও লেখার সহায়তার জন্য আগের Worker AI provider configuration সচল থাকতে হবে এবং Settings-এ AI processing অনুমতি চালু থাকতে হবে। Document Scanner Google Play Services থেকে প্রয়োজনীয় component ডাউনলোড করে; প্রথম ব্যবহারে নেটওয়ার্ক লাগতে পারে।

## Firestore Rules deploy করুন (২৪ ঘণ্টার Notes-এর জন্য জরুরি)

Notes-এর লেখা `users/{uid}`-এর broadly-readable profile-এ রাখা হয় না। এটি আলাদা `user_notes/{uid}` document-এ থাকে, যেখানে নতুন rules শুধু মালিক ও মালিকের friend list-এ থাকা account-কে read করতে দেয়। আপনার Firebase project-এ পরিবর্তিত `firestore.rules` deploy করুন:

```bash
firebase deploy --only firestore:rules
```

Deploy-এর আগে Firebase CLI-তে সঠিক project select আছে কিনা নিশ্চিত করুন (`firebase use <project-id>`). Rules deploy না করলে Notes read/write permission denied হতে পারে।

## ব্যবহার

- মেসেজে Save / Pin / Remind / Select: bubble-এর action menu থেকে।
- Multi-select: Select চাপুন, তারপর সর্বোচ্চ ১০০টি bubble নির্বাচন করে Copy / Save / Forward / Delete। Delete শুধু নিজের পাঠানো নির্বাচিত সব মেসেজে সক্রিয়।
- Chat lock: Conversation settings → Lock this chat; Android screen lock বা fingerprint/face authentication configure করা চাই।
- Auto-download: Conversation settings → Auto-save received media; Wi-Fi-only ও file-type switch সেখানেই।
- Document scanner: Attachments → Scan to PDF; PDF chat-এ পাঠানো হবে।
- Storage manager: Profile & settings → Smart tools → Saved, calls & global search → Storage manager; এখানে শুধু DownloadManager-এ Convo Chat তৈরি করা ফাইল remove হবে।
- AI Catch me up: chat top bar-এর AI button; Writing tools: খসড়া লিখলে composer-এর উপরে।
- ২৪ ঘণ্টার Notes: Messages tab-এর note bubble; সর্বোচ্চ ৮০ অক্ষর, friends-only Firestore rule.
