# Convo Chat v4.4.3 — chat-list refresh, safe insets ও smart tools

## এই আপডেটে

- **চ্যাট লিস্টে জায়গা ফেরত:** শীর্ষবারে screenshot-ধাঁচের দ্রুত App lock shortcut-ও আছে; চালু থাকলে disable করার আগে confirmation লাগে। Saved, Call history, cached-message search, contact discovery, Notes ও All/Unread/Archived/Locked filter এক expand/collapse করা **Tools & filters** প্যানেলে। মানুষ খোঁজার সার্চ ও Active now strip দ্রুত পাওয়া যায়।
- **চ্যাট সারির compact polish:** ছোট avatar/card, unread status, delivery tick, active dot এবং শেষ মেসেজের সময়—কম vertical space-এ বেশি conversation।
- **Full-screen safe area:** Saved/Calls/Search/Storage tools overlay এখন status bar, navigation bar ও keyboard insets মেনে চলে। Conversation settings ও text-file viewer-এ bottom navigation inset-ও রাখা হয়েছে।
- **আধুনিক call history:** নাম দিয়ে search, All/Missed/Incoming/Outgoing filter, summary counters, সময় ও outcome, single-item remove, এবং এক ট্যাপে audio/video callback। কল রেকর্ড এখনও device-local; app data মুছলে হারাতে পারে।
- **Smart theme:** Android 12+ এ wallpaper-derived palette এবং system light/dark mode অনুসরণ করে; পুরোনো Android-এ accessible light/dark fallback। আগের theme-গুলো অক্ষত।
- **Dynamic loading:** local cached-message search-এ app theme-এর accent/tertiary রঙে animated loading treatment।
- **Verification convenience:** Firebase Phone Auth-এর instant verification/SMS auto-retrieval আগের মতোই আছে; OTP field-এ clipboard paste shortcut যোগ হয়েছে। 2-step verification code/backup-code field-এও paste button যোগ হয়েছে।

## কী সেটআপ লাগবে

- এই UI আপডেটের জন্য **নতুন API key লাগবে না**।
- Audio/video callback-এর জন্য বর্তমান Firebase Auth/Realtime Database signaling এবং app-এ ইতিমধ্যে ব্যবহৃত Worker/TURN configuration-ই লাগে।
- Phone sign-in চালু রাখতে Firebase Console-এ Phone provider, project-এর app signing SHA fingerprints, quota/allowed regions এবং test phone numbers ঠিক থাকতে হবে। SMS auto-retrieval/instant verification ডিভাইস, Google Play services, network, SMS format ও Firebase policy-র ওপর নির্ভরশীল; প্রতিটি ফোনে guaranteed নয়। Android code SMS permission চায় না।
- Android 12+ wallpaper dynamic palette ব্যবহার করে; user theme “Smart” বেছে নিতে হবে। অন্য Android version-এ fallback palette ব্যবহৃত হয়।

## সীমা ও যাচাই

- Search local device cache ব্যবহার করে; server-wide/full-text search নয়।
- Call history এখনও ব্যক্তিগত/local; cross-device sync, group-call log, scheduled calls বা cloud backup এই আপডেটে যোগ হয়নি। callback-ও বিদ্যমান 1:1 call flow-এর ওপর নির্ভর করে।
- SMS auto-retrieval Firebase Play services, network, SMS format ও policy-নির্ভর; clipboard paste হলো manual fallback। Firebase instant verification code field পূরণ ছাড়াও সরাসরি credential sign-in করতে পারে।
- Full app-wide redesign নয়—chat list, call history, tools overlay, verification fields এবং নির্দিষ্ট fullscreen safe-area-র targeted update।
