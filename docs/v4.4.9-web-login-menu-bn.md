# v4.4.9 — ওয়েব ইমেইল লগইন, সীমাহীন সেশন, মেনু নতুন ডিজাইন (versionCode 55)

**Release:** versionCode **55**, versionName **4.4.9** · Worker API **v51** / Worker release **4.8.0**

## ১. "Link my browser" ক্র্যাশ ফিক্স

সমস্যা: **Link my browser** টিপলেই `Must not be called on the main application thread`।
কারণ: `Tasks.await(...)` (Firebase ID token) মেইন থ্রেডে চলছিল — `viewModelScope`
ডিফল্টে `Dispatchers.Main` ব্যবহার করে, আর OkHttp কল `Dispatchers.IO`-তে থাকলেও
`Tasks.await` থ্রেডে ছিল না।

ফিক্স (`ChatViewModel`):
- `createWebCompanionPairing` ও `revokeWebCompanionSessions` — পুরো নেটওয়ার্ক+টোকেন
  এক্সচেঞ্জ `withContext(Dispatchers.IO)`-তে সরানো হয়েছে।
- `authedJsonCall` ও `deleteSupabaseObject` — `runBlocking(Dispatchers.IO)` দিয়ে
  হার্ডেন করা হয়েছে যাতে যেকোনো কলার থেকে মেইন-থ্রেড এরর আর না আসে।

## ২. ওয়েব সেশনে কোনো সময়সীমা নেই

আগে ব্রাউজার সেশন ১২ ঘণ্টায় শেষ হতো (`WEB_SESSION_HOURS = 12`)। এখন:
- Worker-এ নতুন সেশনে `expiresAt = 0` (০ = কোনো সীমা নেই)।
- `authenticateWebCompanionSession` ও সাইটের `readSession` `expiresAt > 0` হলেই
  মেয়াদ যাচাই করে; ০ মানে সাইন-আউট/রিভোক না করা পর্যন্ত সাইন-ইন থাকবে।
- সব "১২ ঘণ্টা" টেক্সট আপডেট করা হয়েছে (অ্যাপ + ওয়েব)।
- পুরোনো সেশন তাদের আগের মেয়াদে শেষ হবে; নতুনগুলো অসীম।

## ৩. ওয়েবে ইমেইল লগইন (login save)

- নতুন Worker রুট `POST /web-pair/login` — অ্যাপের একই ইমেইল/পাসওয়ার্ড Firebase Auth
  (`accounts:signInWithPassword`) দিয়ে যাচাই হয়; ব্রাউজার শুধু অস্বচ্ছ
  `sessionToken` পায় (কোনো Firebase ক্রেডেনশিয়াল নয়)। রেট-লিমিট: IP প্রতি মিনিটে ৫ বার।
- সাইটের কানেক্ট স্ক্রিনে নতুন **ইমেইল লগইন ফর্ম** ("Sign in & save this browser") —
  localStorage-এ লগইন সেভ থাকে, তাই পরের বার আসলেই সাইন-ইন থাকবে।
- Worker binding: `FIREBASE_WEB_API_KEY` (plain_text)।
