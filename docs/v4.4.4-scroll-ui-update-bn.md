# Convo Chat v4.4.4 — scroll-responsive Chats UI

## বাস্তবায়িত

- **Down-scroll collapse:** chat list ~20dp scroll করলে full brand/status app bar, `Tools & filters` card, expanded tools এবং `Active now` contacts strip vertical expand/shrink + fade/slide animation-এ hide হয়।
- **Search pinned:** মানুষ খোঁজার bar দৃশ্যমান থাকে; header collapse হলেও user search ব্যবহার করতে পারে।
- **Auto-close expanded tools:** expanded tool panel খোলা থাকা অবস্থায় list scroll শুরু হলে panel বন্ধ হয়, যাতে conversation list-এর উচ্চতা বাড়ে।
- **Scroll-to-top restore:** list-এর শুরুতে/উপরে ফিরলে top app bar, online/offline status, tool card এবং online contacts strip animation-এ ফিরে আসে।
- **Safe system area:** collapsed অবস্থায় status-bar spacer থাকে; content status area-র নিচে যায় না। Bottom navigation ও বিদ্যমান route অপরিবর্তিত।
- Search/filter/empty results state-এ stale collapse state না রাখার জন্য scroll signal displayed conversation list-এর সঙ্গে যুক্ত।

`docs/app-experience-audit-plan-bn.md`-এ app-এর launch/auth, home feed, stories/reels, chat list, 1:1 chat, groups, calls, search/discovery, profile/settings, security, AI/Notes/Saved/files, admin, notifications/presence—সব screen family-র বর্তমান surface, redesign proposal, visual/accessibility rules, acceptance checks ও phased priority রাখা হয়েছে।

## Setup ও missing keys

- এই UI change-এ নতুন API key, permission, Worker endpoint বা Firebase rule লাগবে না।
- Existing Firebase/Worker/phone-auth setup আগের মতোই। Phone sign-in-এর জন্য Firebase Console Phone provider এবং app signing SHA fingerprints সঠিক থাকতে হবে।
- পূর্বের `user_notes/{uid}` Firestore rules deployment এখনো জরুরি হতে পারে Notes data ব্যবহারের জন্য; এটি এই release-এ পরিবর্তন করা হয়নি।
