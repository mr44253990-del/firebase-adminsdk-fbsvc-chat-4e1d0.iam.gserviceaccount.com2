# v4.4.6 — Service health & update (versionCode 52)

**Release:** versionCode **52**, versionName **4.4.6** · Worker **API v50 / release 4.7.0**
**Primary Worker:** `https://convo-chat-companion.mr4425390.workers.dev`

## কী ঠিক করা হলো (What was fixed)

1. **GitHub অটো-ডিপ্লয় ভুল Worker-এ পাঠাত।** `.github/workflows/deploy-backend.yml`-এ
   ডিফল্ট `WORKER_NAME` ছিল `solitary-hill-dcdc` এবং verify URL-এ সাবডোমেইন টাইপো ছিল
   `mr44253990` (একটি বাড়তি `9`)। এখন ডিফল্ট `convo-chat-companion` এবং সাবডোমেইন
   `mr4425390` — অর্থাৎ অ্যাপের প্রাইমারি URL-এর সাথে হুবহু মিলে যায়। সাবডোমেইনটি এখন
   `WORKER_SUBDOMAIN` repository variable দিয়ে ওভাররাইড করা যায়।
2. **Verify ধাপটি এখন অর্থবহ।** আগে শুধু `apiVersion` আছে কি না দেখত। এখন লাইভ Worker থেকে
   প্রত্যাশিত API ভার্সন (`cloudflare-worker.js` থেকে পড়া) এবং `serviceAccountConfigured`
   দুটোই মিলিয়ে দেখে, ব্রাউজার-সদৃশ হেডার পাঠায় (ডিফল্ট urllib UA-তে Cloudflare 403 দিত),
   এবং ১২ বার পর্যন্ত পোল করে।
3. **বান্ডল্ড Worker asset পুরোনো ছিল।** `app/src/main/assets/worker/cloudflare-worker.js`
   API 46-এ আটকে ছিল; এখন তিনটি কপিই (`cloudflare-worker.js`, `firechat-fcm-worker.js`,
   bundled asset) API 50-এ সিঙ্ক করা।

## Service health উন্নতি

- Worker health endpoint এখন সত্যিকারের `emailConfigured` (আগে হার্ডকোড `true`),
  `emailProviders`, `searchConfigured`, `webCompanionConfigured`, `appDownloadConfigured`,
  এবং Cloudflare `colo`/`country` রিপোর্ট করে। ভার্সন স্ট্রিং এখন `WORKER_RELEASE` ধ্রুবক থেকে আসে।
- Android `WorkerHealth.Report`-এ নতুন ফিল্ড যোগ হয়েছে এবং `checkAll()` এখন সব Worker
  **parallel**-এ প্রোব করে (`async`/`awaitAll`) — একটি ধীর নোড বাকিদের আটকায় না।
- `Admin → Server health` প্যানেল এখন লাইভ Worker ভার্সন, ডেটা সেন্টার, এবং অতিরিক্ত চিপ
  (Email, Search, Web app, APK link) দেখায় এবং প্রতি ৬০ সেকেন্ডে নিজে থেকে রিফ্রেশ হয়।

## ডিপ্লয় নোট (গুরুত্বপূর্ণ)

এই push-এর পর লাইভ Worker এখনো API 49-এ থাকবে যতক্ষণ না রি-ডিপ্লয় করা হয়। রিপোজটরিতে
এখনো `CLOUDFLARE_API_TOKEN` secret নেই, তাই অটো-ডিপ্লয় আপাতত skip হবে। লাইভ API 50-এ
আনতে যেকোনো একটি করুন:

- অ্যাপে **Admin → Server health → Deploy now** (বান্ডল্ড API 50 কোড আপলোড হবে, সব secret/binding অক্ষত থাকবে), অথবা
- GitHub **Settings → Secrets and variables → Actions**-এ `CLOUDFLARE_API_TOKEN`
  (Workers Scripts: Edit) যোগ করুন — এরপর প্রতিটি push স্বয়ংক্রিয়ভাবে সঠিক Worker-এ ডিপ্লয় হবে।

রি-ডিপ্লয়ের আগ পর্যন্ত অ্যাপের হেলথ প্যানেল লাইভ Worker-কে "update needed" দেখাবে, যা
প্রত্যাশিত আচরণ; বিদ্যমান রাউটগুলো কাজ করা বন্ধ করে না।
