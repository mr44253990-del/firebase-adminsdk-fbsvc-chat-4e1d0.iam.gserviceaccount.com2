# v4.4.8 — R2 মিডিয়া, Cloudflare টোকেন ফিক্স, ওয়েব লাইভ (versionCode 54)

**Release:** versionCode **54**, versionName **4.4.8** · Worker API **v50** / Worker release **4.7.1**

## ১. "Cloudflare rejected the API token" — কারণ ও সমাধান

নতুন ধরনের Cloudflare **account-scoped token** (`cfat_…`, ৫৩ অক্ষর) `GET /user/tokens/verify`
এ "Invalid API Token" (401) দেয়, অথচ অ্যাকাউন্ট API-তে (`/accounts`, workers, R2, Pages)
সম্পূর্ণ কাজ করে। আমাদের deploy ফ্লো প্রথমে verify কল করত, তাই সঠিক টোকেন থাকলেও
"Cloudflare rejected the API token" দেখাত।

**ফিক্স:**
- Worker `/admin/web-deploy/*`: verify এখন তথ্যতাত্ত্বিক; কর্তৃত্ব যাচাই হয়
  `GET /accounts/{accountId}` দিয়ে। টোকেন কাজ করলেই deploy হয়।
- অ্যাপের `WorkerDeployer.verifyToken` একইভাবে account-scoped টোকেন গ্রহণ করে।
- Worker-এ সংরক্ষিত ফলব্যাক (`CLOUDFLARE_API_TOKEN`/`CLOUDFLARE_ACCOUNT_ID` secret) আপডেট করা হয়েছে,
  ফলে টোকেন না দিয়েও অ্যাডমিন deploy করতে পারবেন।

## ২. R2 মিডিয়া ("r2 add" সমস্যা)

লাইভ Worker-এ `MEDIA_BUCKET` binding ছিল (`search-backend-media`), কিন্তু
**`R2_PUBLIC_BASE_URL` ছিল না** — তাই প্রতিটি `/media/upload` ৫০৩ দিচ্ছিল।

**ফিক্স:**
- `R2_PUBLIC_BASE_URL` binding যোগ হয়েছে।
- Worker-এ নতুন **পাবলিক ডেলিভারি রুট** `GET /media/f/<key>` — চ্যাট ছবি, রিল,
  অ্যাভাটার ও APK সরাসরি R2 থেকে স্ট্রিম হয় (কী-গুলো অনুমেয় UUID, তাই নিরাপদ)।
- অনুমত প্রিফিক্স: `posts/ reels/ thumbnails/ updates/ avatars/ web_site/`।

## ৩. ওয়েব কম্পানিয়ন লাইভ

- `web-companion/site` বিল্ড Cloudflare Pages প্রজেক্ট **`convo-chat-companion`**-এ
  ডিপ্লয় হয়েছে → **https://convo-chat-companion.pages.dev**
- Worker binding: `WEB_COMPANION_ORIGIN` = উপরের URL, তাই health-এ `webCompanionConfigured: true`।
- `FIREBASE_DATABASE_URL` binding যোগ → web pairing/clouddb রুট সচল।
- অ্যাপের Web deploy স্ক্রিনে অ্যাকাউন্ট ID (`e86734d4…4d0`) ও প্রজেক্ট
  (`convo-chat-companion`) ডিফল্ট হয়েছে।
