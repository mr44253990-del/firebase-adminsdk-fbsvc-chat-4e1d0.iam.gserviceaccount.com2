# Convo Chat v4.5.0 (versionCode 56) — ওয়েব লাইভ চ্যাট, সাইন আপ, কল স্কিন

ওয়ার্কার: **v4.9.0 / API 52** · ওয়েব: https://convo-chat-companion.pages.dev

## মূল কারণ (Root cause)
1. **"Message send failed (401)"** — ওয়ার্কার Realtime Database-এ সার্ভিস-অ্যাকাউন্ট OAuth টোকেন `Authorization: Bearer` হেডারে পাঠাত, যেটা ডাটাবেস রুলস প্রত্যাখ্যান করছিল (401)।
   **সমাধান:** নতুন `webPairFetch()` লেয়ার — প্রথমে `access_token=` (সার্ভিস অ্যাকাউন্ট), কাজ না করলে ইউজারের জন্য তৈরি করা Firebase ID টোকেন (`auth=`, custom-token exchange) দিয়ে আবার চেষ্টা করে; যেটা কাজ করে সেটা মনে রাখে।
2. **মেসেজ থাকা সত্ত্বেও "Say hello"** — RTDB রিড URL-এ `.json` ছিল না এবং `print=silent` বডি মুছে দিচ্ছিল → সব রিড খালি আসত। `webPairDbUrl()` এখন সঠিক `<db>/<path>.json?query&auth` বানায়।
3. **মেসেজ বক্স মাঝখানে** — `#stream-host`-এ কোনো CSS ছিল না, তাই flex কাজ করত না। এখন `flex:1; min-height:0; display:flex`।

## লাইভ E2E টেস্ট (ডিপ্লয় করা ওয়ার্কারে)
signup ×2 → find → friend-request → friend-requests → friend-respond(accept) → send A→B **200** → send B→A **200** → messages (দুটো মেসেজ ফিরে আসে) → chats (lastMessage + unread) → typing → read ✅

## নতুন ওয়ার্কার রুট
| রুট | কাজ |
|---|---|
| `POST /web-pair/signup` | নাম + ইমেইল + পাসওয়ার্ড → Firebase Auth অ্যাকাউন্ট + `users/{uid}` প্রোফাইল + আনলিমিটেড ওয়েব সেশন (IP প্রতি মিনিটে ৫ বার) |
| `POST /web-pair/find` | হুবহু @username বা ইমেইল দিয়ে মানুষ খোঁজা |
| `POST /web-pair/friend-requests` | আসা পেন্ডিং রিকোয়েস্ট |
| `POST /web-pair/friend-request` | রিকোয়েস্ট পাঠানো (উল্টো রিকোয়েস্ট থাকলে সরাসরি বন্ধু) + অ্যাক্টিভিটি নোটিফিকেশন + FCM পুশ |
| `POST /web-pair/friend-respond` | অ্যাকসেপ্ট/ডিক্লাইন (অ্যাপের মতো একই `friend_requests` ডক) |

## ওয়েব
- কিবোর্ড-সচেতন লেআউট: `interactive-widget=resizes-content`, visualViewport → `--app-h`/`--kb`, `body.kb-open`, ইনপুট ≥16px।

- মেসেজ স্ক্রিন: গ্রেডিয়েন্ট হেডার, নরম বাবল, গ্লাস কম্পোজার, মোবাইলে চ্যাট খুললে ট্যাববার লুকায়।
- নোটিফিকেশন: লুকানো ট্যাবে ব্রাউজার Notification, টাইটেল ব্যাজ `(n)`, App Badge, ইন-অ্যাপ টোস্ট; ব্যাকগ্রাউন্ডে ধীরে পোলিং চলে।
- Discover: ফ্রেন্ড রিকোয়েস্ট সেকশন + "People on Convo Chat" + Add friend; Discover ট্যাবে ব্যাজ।
