# Convo v4.3.x — নতুন ফিচার ও ডিপ্লয় নোট

## যা যোগ হয়েছে
- **Smart multi-worker routing** (Admin → Smart multi-worker routing): Primary worker URL ছাড়াও আরও 4টি worker URL যোগ করা যায়। প্রতিটি সার্ভিস (push, calls, ai, storage, database, location) একসাথে শুধু একটি worker-এ চলে। Secondary-তে কোনো সার্ভিস চালু করলে Primary থেকে সেটা আপনা-আপনি বন্ধ হয়ে যায়। Secondary worker সেট না থাকলে বা ফেল করলে ২ মিনিটের জন্য Primary-তে ফিরে যায়।
  - RTDB: `config/app_settings/workerPool/{id}`
  - সব secondary worker-এ Primary-র মতো একই secrets/bindings থাকতে হবে।
- **AI providers & keys** (Admin): key আপডেট করা, Test চাপলে মডেলের তালিকা দেখা, custom provider (OpenAI-compatible) যোগ করা, AI লুকানোর সুইচ। Key রাখা হয় Firestore `admin_secrets/ai`-এ, যা শুধু admin পড়তে পারে।
- **Location sharing**: চ্যাটে + → Location।
  - Current location: 1–2 সেকেন্ড লোড হওয়ার পর লিংক ও coordinates পাঠায়।
  - Live location: 10 মিনিট থেকে 8 ঘণ্টা পর্যন্ত। Foreground service notification দেখিয়ে অ্যাপ বন্ধ থাকলেও শেয়ার চলতে থাকে। প্রাপক OpenStreetMap ম্যাপে লাইভ অবস্থান দেখতে পান।
  - Admin চাইলে পুরো ফিচারটা বন্ধ করতে পারেন।
- **Smart attach sheet**: Gallery, Camera, Document, Audio, Location, Contact, Schedule, APK।
- **Conversation settings ফুল পেজ**: nickname, pin, নির্দিষ্ট সময়ের জন্য mute, quick reaction, text size, disappearing messages। সাথে media/files/links/places, chat insights, export chat, report ও block।
- **Reaction effects**: ফুল-স্ক্রিন অ্যানিমেশন (hearts, burst, rain, firework, bounce, float) এখন শেষ পর্যন্ত চলে। বড় emoji বার্তা pop করে দেখা যায়।
- **নতুন ডিজাইন**: 20টি নতুন cover (anime ও animated), 4টি নতুন scene background, textures সহ 20টি নতুন chat theme, 10টি নতুন app theme। Settings-এর option row রঙিন করা হয়েছে, আর নতুন Smart tools পেজ আছে (quiet hours, reduce motion, live location, storage)।
- **Enterprise**:
  - Admin **Announcements**: সব ইউজারের অ্যাপে banner দেখানো যায়।
  - **Audit log**: admin-এর প্রতিটি পরিবর্তন রেকর্ড হয়।
  - **Download my data**: নিজের ডেটা JSON হিসেবে export করা যায়।
  - Quiet hours।
  - প্রতিটি কথোপকথনের জন্য আলাদা mute।

## ডিপ্লয় করতে হবে
1. `firestore.rules` আবার deploy করুন। এতে `admin_secrets`, `live_locations` ও `admin_audit` যোগ হয়েছে।
2. Cloudflare worker (`cloudflare-worker.js`) আবার deploy করুন, কারণ `/ai/chat` এখন provider বেছে নেয়।
3. Supabase `auto-ai-post` edge function আবার deploy করুন।

## সীমাবদ্ধতা (সততার সাথে)
- Lock-screen/background কল FCM ডেলিভারি, Doze, OEM battery restriction এবং Android 14+ এর full-screen-intent অনুমতির ওপর নির্ভর করে, তাই এটা best-effort।
- Live location-এর জন্য location ও notification অনুমতি লাগে। কিছু ফোন battery saver চালু থাকলে update ধীর করে দিতে পারে।
- ম্যাপ tiles আসে OpenStreetMap থেকে। এটা ফ্রি, কিন্তু বেশি ব্যবহার হলে নিজস্ব tile server বা কোনো map API লাগবে।

# v4.3.3 (42) — নতুন যা এসেছে

## ১. AI: সব জায়গায় একটাই সেটিং
- Admin → **AI providers & keys** পেজে যে provider ও model সিলেক্ট করবেন, শুধু সেটাই ব্যবহার হবে: AI চ্যাট, smart reply, অনুবাদ, Auto AI post — সব জায়গায়।
- "AI & feature flags" থেকে পুরনো "Mistral model" ঘর সরিয়ে দেওয়া হয়েছে। এখন ওখানে শুধু বর্তমান model দেখায়।
- **Save to server** চাপলে Firestore-এ সেভ হয়, আর একটা key ছাড়া সারাংশ `app_config/ai_public`-এ যায়। Worker পরের request থেকেই নতুন model নেয়, ১ মিনিট অপেক্ষা করতে হয় না।
- কোনো provider-এ key/model দিলে আর কিছু active না থাকলে সেটাই নিজে থেকে active হয়ে যায়। model ফাঁকা রাখলে ওই provider-এর default model বসে যায়।
- **Test live server** বাটন Worker দিয়ে সেভ করা model-এ একটা আসল উত্তর এনে দেখায়।

## ২. Cloud backup (Cloudflare D1)

- ছবি, ভয়েস, ফাইল, reaction, tick, typing আর কল আগের মতোই কাজ করে।
- Cloud-এ পৌঁছানো না গেলে মেসেজ আপনা-আপনি আগের মতো Firebase দিয়ে যায়, তাই কোনো মেসেজ হারায় না।
- নতুন ফোনে বা আবার install করলে বন্ধুদের সাথে আগের text history D1 থেকে ফিরে আসে।

# v4.3.4 — বড় আপডেট

## ১. auto-ai-post deploy error ঠিক
- "Module not found presence-monitor/presence.js" আর হবে না: `auto-ai-post` এখন সম্পূর্ণ আলাদা (self-contained)। Dashboard → Edge Functions → `auto-ai-post` → কোড পেস্ট → Deploy।
- AI/D1 কাজ না করার সবচেয়ে সাধারণ কারণ: Worker নতুন কোড দিয়ে redeploy করা হয়নি বা Admin-এ AI/Cloud DB সেটিং ভুল। নিচের Deploy অংশ দেখুন।

## ২. Delivery / tick
- অফলাইন ইউজার অনলাইনে এলে এখন এক টিক → দুই টিক হয় (DeliveryAck: অ্যাপ খুললেই সব pending মেসেজ acknowledge)।
- Like/knock/sticker-এর জন্যও টিক দেখা যায়।

## ৩. Account security (Settings → Account security)
- **2-step verification**: Authenticator app (TOTP) অথবা Email OTP বেছে নিন। চালু থাকলে প্রতিটি নতুন লগইনে কোড লাগবে।
- **Backup codes**: ১০টি এককালীন কোড — copy/share করে রাখুন। ফোন/ইমেইল হারালে Login → Forgot password → "Use a backup code" দিয়ে নতুন পাসওয়ার্ড সেট করা যায় (সব ডিভাইস থেকে sign-out হয়ে যায়)।
- **নতুন ডিভাইসে লগইন হলে** পুরনো ডিভাইসে push + ইমেইল সতর্কবার্তা।
- ৫ বার ভুল কোড দিলে ১৫ মিনিট লক; recovery-তে ৫ বার ভুল দিলে ১ ঘণ্টা লক।
- দ্রষ্টব্য: এটা অ্যাপ-লেভেল গেট (Worker সার্ভারে কোড যাচাই করে)। Firebase-এর নিজস্ব per-session 2FA শুধু Identity Platform (paid) দিয়ে সম্ভব।
- Admin → **Email & 2FA**: Brevo (ফ্রি, verified Gmail sender) অথবা Resend API key দিন → "Send test"।

## ৪. Sub-admin (Admin → Sub-admins & roles)
