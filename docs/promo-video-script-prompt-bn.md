# Convo Chat — প্রোমো ভিডিও স্ক্রিপ্ট ও জেনারেশন প্রম্পট

**ব্যবহার:** Reels / TikTok / YouTube Shorts; 9:16 vertical, 1080×1920, 35–40 সেকেন্ড। নিচের কথাগুলো অ্যাপের বর্তমান ফিচার অনুযায়ী লেখা। AI summary/writing tools দেখানোর আগে Worker-এ AI provider configured থাকতে হবে। ভিডিওতে কোনো ভুয়া rating, user count, encryption claim বা অদেখা স্ক্রিন দেখাবেন না।

## বাংলা ভয়েসওভার (প্রায় ৩৫–৪০ সেকেন্ড)

> আপনার মানুষগুলোর সঙ্গে কথোপকথন—এবার আরও সহজ, আরও গুছানো। Convo Chat-এ ব্যক্তিগত চ্যাট, গ্রুপ, ছবি, ভিডিও, ফাইল আর ভয়েস মেসেজ—সব এক জায়গায়। দরকারি বার্তা সেভ বা পিন করুন, একসঙ্গে একাধিক বার্তা কপি, ফরোয়ার্ড বা মুছুন। অডিও ও ভিডিও কলে কথা বলুন, গ্রুপ কলে যুক্ত হন, স্ক্রিন শেয়ার করুন। প্রয়োজন হলে AI দিয়ে সাম্প্রতিক কথার সারাংশ নিন বা আপনার খসড়া আরও পরিষ্কার করে নিন। কাগজ স্ক্যান করে PDF পাঠান, ডাউনলোডগুলো দেখুন ও নিয়ন্ত্রণ করুন, আর বন্ধুরা কী নোট রেখেছে দেখে নিন। Convo Chat—আপনার প্রতিদিনের যোগাযোগ, এক ছাদের নিচে।

## শটলিস্ট ও স্ক্রিন-টেক্সট

- **০–৪ সেকেন্ড:** ফোন হাতে; কনভো চ্যাটের ব্র্যান্ডেড splash থেকে chat list-এ মসৃণ ট্রানজিশন। টেক্সট: “আপনার কথোপকথন, এক জায়গায়”।
- **৪–১০ সেকেন্ড:** বাস্তব chat UI-তে ছোট কথোপকথন, ছবি/ফাইল bubble; Saved ও Pin action দেখান। টেক্সট: “চ্যাট · ফাইল · Saved · Pin”।
- **১০–১৬ সেকেন্ড:** মেসেজ select করে Copy / Forward toolbar; তারপর Archive filter। টেক্সট: “গুছিয়ে রাখুন”।
- **১৬–২২ সেকেন্ড:** audio call থেকে video call / group call, screen-share দৃশ্য। টেক্সট: “কথা বলুন, দেখান, যুক্ত থাকুন”।
- **২২–২৭ সেকেন্ড:** AI catch-up ও writing tools দেখান—শুধু AI config প্রস্তুত থাকলে। টেক্সট: “কথার সারাংশ · লেখার সহায়তা”।
- **২৭–৩২ সেকেন্ড:** Document Scanner-এ পাতা capture, PDF attachment; তারপর Storage manager। টেক্সট: “স্ক্যান করে পাঠান · ডাউনলোড নিয়ন্ত্রণ”।
- **৩২–৩৭ সেকেন্ড:** বন্ধুদের ২৪ ঘণ্টার note bubbles, call history, শান্ত gradient outro। টেক্সট: “Convo Chat” / “এখনই ব্যবহার করুন”।

## Text-to-video prompt (Runway / Sora / Veo-ধাঁচের টুলে পেস্ট করার জন্য)

```text
Create a polished 38-second vertical 9:16 promotional video for an Android messaging app named “Convo Chat”, aimed at young adults and families in Bangladesh. Contemporary premium product-ad style, believable Android phone mockups, warm human moments, refined deep navy and teal with restrained violet highlights, smooth camera moves, crisp UI close-ups, natural skin tones, subtle ambient light, no clutter, no decorative emoji, no fake ratings, no fabricated user numbers, no claim of end-to-end encryption, no unreadable tiny interface text.

Storyboard: 0–4s an elegant phone reveal transitions to a modern conversation list; 4–10s a real-looking direct chat with text, photo and file bubbles, then the user saves and pins a useful message; 10–16s show multi-select actions and an archive filter; 16–22s show a natural audio-to-video call transition, then a small group video call and a screen-share view; 22–27s show an AI catch-up summary and draft-writing helper only as a subtle optional feature; 27–32s show a document being scanned into a clean PDF attachment, then a storage manager list; 32–37s show friends’ short status notes and a local call-history screen; 37–38s finish on a clean Convo Chat brand card.

Keep all screens plausible for a real Android app. Do not invent extra features, metrics, testimonials, payment brands, or security claims. Do not render decorative emoji. Avoid generating precise written UI labels because text generators often distort them; leave clean negative space for Bengali overlays added in editing. No watermarks. Smooth transitions, cinematic but credible, professional social-media ad, high contrast and accessible.
```

## এডিটিং নোট

AI tool দিয়ে তৈরি শটে লেখা বিকৃত হলে সরিয়ে নিজে overlay দিন। অ্যাপের আসল screenshot/screen recording থাকলে generic mock UI-এর বদলে সেগুলো বসান। ভয়েসওভার স্বাভাবিক, স্পষ্ট বাংলা উচ্চারণে; ব্যাকগ্রাউন্ড মিউজিক low-volume instrumental রাখুন, কথার সঙ্গে যেন প্রতিযোগিতা না করে।
